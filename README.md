# Aamna Brohi — Portfolio

Personal portfolio website of Aamna Brohi, AI developer and Computer Science (AI) student at Sukkur IBA University.

**Where there's a gap, I build.**

## What's inside
- `index.html` — the complete website (HTML, CSS, JavaScript and images in one file)
- `Aamna_Brohi_CV.pdf` — ATS-friendly CV, linked from the "Download CV" buttons

## Sections
About · Projects (UniPath AI, Ilmora Labs, GenAI in Higher Education, Dukhtar Studio) · Experience · Certifications · Leadership · Contact

## Hosting
Static site, hosted with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

## Updating
Edit `index.html`, commit, and GitHub Pages republishes automatically. Replace `Aamna_Brohi_CV.pdf` to update the CV.
